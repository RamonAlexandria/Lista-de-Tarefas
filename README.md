📝 Lista de Tarefas
Um aplicativo simples e funcional de Lista de Tarefas desenvolvido em HTML, CSS e JavaScript. O projeto permite adicionar, marcar como concluída e remover tarefas da lista em tempo real.

🚀 Funcionalidades

➕ Adicionar Tarefas: Digite uma tarefa no campo de texto e clique em "Adicionar" ou pressione Enter.

✅ Marcar/Desmarcar como Concluída: Clique na tarefa para alternar o status. Ao ser concluída, a tarefa recebe um estilo visual (riscado) e é movida para o final da lista.

🗑️ Deletar Tarefas: Remova tarefas da lista a qualquer momento com o botão "Deletar".

🛠️ Tecnologias Utilizadas

HTML5: Estruturação da página.

CSS3: Estilização e layout responsivo.

JavaScript (ES6): Manipulação de elementos do DOM e lógica da aplicação.

Material Design Icons (MDI): Ícones para os botões e marcadores de status.

🔧 Como Executar o Projeto

Clone ou baixe este repositório para o seu computador.

Certifique-se de manter a estrutura de pastas (css/ e js/).

Abra o arquivo index.html em qualquer navegador web de sua preferência.
